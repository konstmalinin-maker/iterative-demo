# Calculator (Iterative Demo)

Учебный проект для сравнения моделей жизненного цикла ПО.

Проект разрабатывается по итеративно-инкрементальной модели: каждая функциональная возможность добавляется отдельным атомарным коммитом.

## Возможности

- Сложение
- Вычитание
- Умножение
- Деление
- Обработка деления на ноль
- CLI-интерфейс
- Юнит-тесты

## Установка

```bash
py -m pip install -r requirements.txt
```

## Использование

Сложение:

```bash
py src/cli.py add 2 3
```

Вычитание:

```bash
py src/cli.py sub 5 3
```

Умножение:

```bash
py src/cli.py mul 4 3
```

Деление:

```bash
py src/cli.py div 10 2
```

## Тестирование

```bash
py -m pytest tests/
```

## Модель разработки

Проект демонстрирует итеративно-инкрементальный подход. Каждая операция, тесты, CLI и документация добавлялись отдельными коммитами.
